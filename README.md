# Page personnelle – Dr. Mamadou Lamine GUEYE

Site statique (un seul fichier `index.html`, autonome).

## Mise en ligne avec GitHub Pages

1. Sur https://github.com, créer un dépôt public nommé `<votre-identifiant>.github.io` (ex. `mamadougueye.github.io`).
2. Dans le dépôt : **Add file → Upload files**, déposer `index.html` (et ce README), puis **Commit changes**.
3. **Settings → Pages** : Source = *Deploy from a branch*, Branch = `main` / `(root)`, puis **Save**.
4. Après 1 à 2 minutes, le site est en ligne à `https://<votre-identifiant>.github.io/`.

## Référencement Google

- Ajouter l'adresse du site dans **Google Search Console** (https://search.google.com/search-console) et demander l'indexation.
- Ajouter le lien du site à vos profils ORCID, Google Scholar et LinkedIn, et à votre page sur le site de l'USO.
